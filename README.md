# Elevate Horizon Connect

**Author:** Ambrose Mathie

## Project Purpose

Elevate Horizon Connect is a mobile app that lists upcoming community events in one place. Each event in the list shows its name, time, location and category tags.

Users can tap an event to see more detail, including the date and a full description. From there, they can press **Register**, which opens a registration form. Once they fill in the required fields and submit, they're registered as a participant in that event.

## Target Audience

| Audience | Description |
| --- | --- |
| **Residents** | General community members who browse the app to stay informed. They can search events, view event details and register their interest in attending. |
| **Volunteers** | People who register to help run or assist with events. They use the same search, view and registration features as every other user. |
| **Community Members** | People who register to take part in and experience events as attendees, using the core features. |
| **Staff** | People who can add, update and delete event listings. These features are part of the same build and are available without signing in. |

## Core Features

- Clear navigation between the **Home**, **Events**, **Registration** and **Settings** screens
- Event listings that display event information accurately
- Search and filter options to find events by keyword or date
- An event registration form for users to register their interest
