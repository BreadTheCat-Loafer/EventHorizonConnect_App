# Elevate Horizon Connect

**Author:** Ambrose Mathie

## Project Purpose

Elevate Horizon Connect is a mobile app for a local council that lets residents, volunteers and community members view and search community events, see event details, and register their interest. It also supports staff management of event listings, all within a single MVP build.

Each event in the list shows its name, time, location and category tags. Users can tap an event to see more detail, including the date and a full description. From there, they can press **Register** to open a registration form, fill in the required fields and submit it to be registered as a participant.

## Target Audience

| Audience | Description |
| --- | --- |
| **Residents** | General community members who browse the app to stay informed. They can search events, view event details and register their interest in attending. |
| **Volunteers** | People who register to help run or assist with events. They use the same search, view and registration features as every other user. |
| **Community Members** | People who register to take part in and experience events as attendees, using the core features. |
| **Staff** | People who can add, update and delete event listings. These features are part of the same build and are available without signing in. |

## Core Features

- View today's events and browse all events
- Search and filter events by keyword or date
- View event details and register interest
- Settings screen (text size, light/dark theme, sound toggle)
- Navigation between Home, Events, Register and Settings
- Add, update and delete event listings (staff perspective)
